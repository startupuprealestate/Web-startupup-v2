# house-story — หน้าเล่าเรื่องบ้านแบบเลื่อนดู

หน้าเดี่ยว ๆ ไม่มี framework ไม่มี build step วางไว้ใน `public/` เพื่อให้เปิดได้ตรง ๆ

เปิดที่ **`/house-story/index.html`**

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครง DOM ทั้งหมด (ฉาก, หัวเว็บ, แผ่นข้อความ, สไลเดอร์) |
| `styles.css` | ตำแหน่ง/หน้าตาทั้งหมด ค่าจริงถูกป้อนผ่าน CSS custom properties |
| `script.js` | เอนจินอนิเมชัน : สกอลล์หน่วง + พารัลแลกซ์เมาส์ + จังหวะแต่ละฉาก + สไลเดอร์วนไม่รู้จบ |
| `img/` | ภาพบริษัท (ย่อ/แปลงเป็น JPEG แล้ว) + ไอคอนสี่เหลี่ยมของการ์ด |

## ลำดับฉากตามระยะเลื่อน (`STORY_LENGTH = 9000px`)

| ระยะ | เกิดอะไร |
|---|---|
| 0 – 650 | ชื่อ `STARTUP UP` ลอยขึ้นแล้วจาง ข้อความเปิดจมลง |
| 560 – 1400 | บานประตูไม้ (ภาพ `หน้าบ้านปิดประตู` ผ่าครึ่งด้วย `clip-path`) แยกออกซ้าย/ขวา เผยภาพ `หน้าบ้านเปิดประตู` ที่อยู่ข้างหลัง |
| 1300 – 1740 | บานประตูลอยพ้นเฟรมและจางหาย = เดินผ่านประตูเข้ามาแล้ว |
| 1760 – 2280 | เลี้ยวกล้องไปเจอ `ในสวน 1` |
| 1900 – 3150 | หัวข้อ "แล้วบ้านหลังนี้ก็เป็นของคุณ" + ปุ่ม `ดูบ้านทั้งหมด` |
| 1980 – 2480 | การ์ดจุดเด่น 5 ใบบินเข้ามาจากขวา (`420vw`) |
| 2380 – 2620 | ปุ่ม ← → โผล่ กดได้เมื่อจางเข้ามาเกิน 98% |
| 2950 – 3320 | การ์ดบินออกทางซ้ายก่อนเปลี่ยนฉาก |
| 3450 – 3970 | เลี้ยวกลับไปเจอ `ในสวน 2` |
| 4600 – 5120 | ดอลลี่เข้าบ้าน `ในบ้าน 1` |
| 5750 – 6270 | `ในบ้าน 2` |
| 6900 – 7420 | `ในบ้าน 3` |
| 7950 – 8470 | `ในบ้าน 4` (ฉากจบ) |

## ฟอนต์

| ใช้ที่ไหน | ฟอนต์ |
|---|---|
| หัวเรื่องใหญ่ / โลโก้ / `h2` / ตัวเลข — ตัวอังกฤษกับตัวเลข | **Cinzel** (Google Fonts) |
| หัวเรื่องเดียวกัน — ตัวอักษรไทย | **Noto Serif Thai** (Cinzel ไม่มีตัวไทย เบราว์เซอร์สลับให้เองรายตัวอักษร) |
| คำบรรยาย / การ์ด / เมนู | **Prompt** |

## ความคมของภาพกับการซูม

ภาพต้นฉบับทุกใบกว้าง **1672 x 941 px** ซึ่งเป็นเพดานความคมของหน้านี้ — ทุกเปอร์เซ็นต์ที่ซูมเกิน 100% คือความคมที่หายไป จึงตั้งค่าไว้แบบนี้

| ค่า | อยู่ที่ | ทำอะไร |
|---|---|---|
| `BASE_SCALE = 1.03` | `script.js` | สเกลพื้นฐาน เผื่อขอบไว้ให้พารัลแลกซ์เมาส์แค่พอดี |
| `dolly` (0.09 – 0.15) | `SCENES` | ระยะดอลลี่เดินหน้าตลอดช่วงชีวิตของฉาก |
| `guard` (0.08 – 0.24) | `SCENES` | สเกลกันขอบตอนภาพยังเลื่อน/หมุนอยู่ ลดได้ถ้าลด `turnX` กับ `ry` ด้วย |
| `--fx` | `script.js` | ใส่ `blur()`/`brightness()` เฉพาะตอนเปลี่ยนฉาก ตอนอยู่นิ่งเป็น `none` เพื่อไม่ให้เบราว์เซอร์ต้องแรสเตอร์ผ่านชั้น filter |

ถ้าอยากได้คมกว่านี้อีก ต้องใช้ไฟล์ต้นฉบับที่ความละเอียดสูงกว่า 1672px แล้วรันสคริปต์แปลงใหม่ (คุณภาพ JPEG ตอนนี้ตั้งไว้ที่ 93)

## แก้จังหวะได้ที่ไหน

- ลำดับฉาก / ความเร็วดอลลี่ / องศาเลี้ยว → `SCENES` ใน `script.js`
- ช่วงที่แผ่นข้อความโผล่-หาย → `PANELS` ใน `script.js`
- ความยาวหน้าโดยรวม → `STORY_LENGTH` ใน `script.js` **และ** `.cinema-scroll { height }` ใน `styles.css` (ต้องแก้ทั้งคู่ให้ตรงกัน)

## ลิงก์ตรงไปยังจังหวะที่ต้องการ

ต่อท้าย URL ด้วย `?at=<ระยะเลื่อน>` เช่น `/house-story/index.html?at=3470` เพื่อกระโดดไปฉากสวน 2 ทันที
สะดวกตอนไล่ปรับจังหวะ
